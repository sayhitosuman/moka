# ✨ UI Upgrade: Premium Loading Skeleton

## The Change
I replaced the old "spinning bucket" loader with a high-end **Skeleton Loader**.

## What It Looks Like
- **Layout Mirroring**: The loader mimics the actual profile layout (Banner, Avatar, Info).
- **Pulse Effect**: A subtle grey shimmer (`animate-pulse`) shows activity.
- **Neubrutalist Elements**: Retained the bold borders and shadows even in the loading state.
- **Sync Badge**: A small, technical-looking badge "SYNCING_PROFILE_DATA..." floating in the center.

## Why It's Better
- **Perceived Speed**: It feels faster because users see the *structure* immediately.
- **Less "Broken"**: Spinners can look like an error. Skeletons look like "loading data".
- **Consistent Design**: Matches the blocky, high-contrast aesthetic of the rest of the app.

## How to Test
1. Click on any user profile (friend, club member, or post author).
2. Watch the brief loading animation.
3. It should cleanly transition into the real data.

No more "rotting bucket"! 🎨
